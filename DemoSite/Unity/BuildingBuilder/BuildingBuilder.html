Building Builder

Building Builder lets you create a variety of Low-poly buildings from a defined list of settings. Each building is created by a collection of options that can easily be changed or set to use a random set of values. Every building comes in three conditions - clean, unkept and run down - with over twenty texture styles included.

This page covers the 2026 version of Building Builder. If you are using an older release, the Legacy version (2017) page is still available.

Overview


You just set the style of house to use and then let the randomiser create a building within the parameters of your chosen building style. After you have created your random building you can tweak the options to make it just as you need it.

Building builder is ideal for any low poly games that need a lot of buildings, or just as a background building for higher detail games.

Every building can be shown in three conditions - clean, unkept and run down - so the same street can have well kept homes next to boarded up, overgrown ones.

New in 2026

The 2026 release is a big update to the textures and the way buildings can look, while keeping the same simple workflow.

Three conditions every building can be Clean, Unkept (dirty) or Unused (run down) - switch with one click or let the randomiser decide.
16 new texture styles brick, stone, render, timber, log and more - 21 styles in all, each in all three conditions.
Random weather tick which conditions 'Randomize Building' may pick, plus a 'Randomize Weather' button.
Texture letters door styles B and C and the garage door X can now be set by hand and are kept when you rebuild.
Fixes garages now sit flush with the house on odd sized buildings, the terrain modifier covers the garage as well, and the package builds cleanly in player builds.

Existing scenes and prefabs carry on working: the materials you have set up are untouched and are simply used as the Clean condition.

Create First Building


To start creating random buildings you just need to add the prefab of your chosen building type from the selection in the prefab folder.

Town house (basic)

And then just click on the 'Randomize Building' button.
That's your first house created. You can continue to click on the 'Randomize Building' button if you need something different.



After you have created your building you can still customize it, so maybe you like the building but you just need it a bit wider, or you need to add a garage - you can just modify the settings and click on 'Create Building'



You can set the size of each building section by changing the Building Units.



This means you don't need to change the transform scale, so the buildings are more likely to get batched when rendering.

Randomization



When you have a building or group of buildings selected you should see all the randomization options in the inspector. This area can be used to help define the look of the house when you press the randomize building button.

If you don't want an option to be randomized just un-tick the option.

The three tick boxes under the 'Randomize Building' button (Clean, Unkept, Unused) choose which conditions the building may be given when it is randomized. Only Clean is ticked to start with, so buildings stay clean unless you say otherwise.


Setting Textures



You can re-randomise the arrangement of textures by using the "Randomize Textures" button. You can also edit them manually by changing the letters in the Textures Details section. Here each texture used is represented with a letter.

W Wall
G Window (Glass)
D Door (style A)
B Door (style B)
C Door (style C)
X Garage door (town house)

Letters are arranged by each wall and then by floor, so...
GD,WW,GG,WW
is a single floor building with a width of 2 and a depth of 2.

The front of the building will have a window and a door [GD]
The side has just walls [WW]
The back has two windows [GG]
The other side has two walls [WW]


Note : If you change the size of the house, the letters are only kept if you also edit them to match the new size (one line per floor, one letter per wall section). Otherwise a new random arrangement is created.

Weathering

Every texture comes in three conditions, so a building can look brand new, a bit neglected, or abandoned - all from the same prefab and the same layout.

Clean
As designed.
Unkept
Dirty: grime, rain streaks, damp, moss and dirty glass.
Unused
Run down: boarded up windows and door, broken glass, missing roof tiles, cracks and ivy.


In the inspector the Weathering row has a button for each condition - the current one is shown pressed. Clicking one swaps the material straight away without rebuilding the mesh, so your window and door layout is untouched.

'Randomize Weather' picks one of the conditions ticked under the 'Randomize Building' button, and 'Randomize Building' itself does the same, so a whole street can be randomized in one click.

The weathered materials live next to the clean ones, in Materials/Clean, Materials/Unkept and Materials/Unused (with the textures in the matching Textures folders). They are named after the clean material with _Unkept or _Unused added, which is how the builder finds them - so if you make your own texture, just follow the same naming and the buttons will pick it up.

Materials

When a building is created / randomized it will pick one of the materials from this list. For most buildings you may only have one material, but for others you may wish to make the building look different. So just add as many variations as you need to this list and the randomiser will pick one for you. If you wanted 1 out of 10 buildings to look like they are made of stone and not brick, you would add 10 materials to this list, 9 of them red brick and 1 stone. See the 'VillageHouse(Variety)_pf' prefab for an example of this.

You can add / use materials, textures and shaders as you need. Because Building builder assigns the material from the list it lets you set-up any normal maps and specular maps as you would for a normal asset.

Below the main list there are two more lists, Unkept Materials and Unused Materials. These hold the weathered version of each material, matched by position in the list. You do not normally need to fill these in: the first time you press a weathering button the builder finds them for you by name.

Baked Light Map Support



With the release of Version 1.2 (June 2017) you can now use the building with Baked lighting. Just enable the new Baked Lighting option and adjust the unwrapping options.

The Unwrapping options are the current default import options on normal mesh import.
